LearnBeat

A tiny drum machine made from scratch. Click steps to create a rhythm, press play, change the BPM, and inspect the source code to learn how the browser can synthesize sound using the Web Audio API.

16-step sequencer

1. HTML = structure

The controls and sequencer live in ordinary HTML elements such as button, input, and div.

2. CSS = appearance

CSS controls colors, spacing, grid layout, hover effects, responsive behavior, and the visual state of active steps.

3. JavaScript = behavior

JavaScript stores the beat pattern, advances the playhead, responds to clicks, and creates the kick, snare, hi-hat, and clap sounds.
